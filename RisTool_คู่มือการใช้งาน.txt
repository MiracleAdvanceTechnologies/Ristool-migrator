====================================
  คู่มือการใช้งาน RisTool
====================================

โปรแกรมนี้ใช้สำหรับแปลงข้อมูลใน Database ของระบบ RIS
- แปลงข้อมูล HTML → JSON
- แปลงค่า 0/1 → N/Y


====================================
  การเริ่มต้นใช้งาน
====================================

1. เปิด cmd แล้วพิม dotnet run 
2. โปรแกรมจะถามข้อมูล Connection String เพื่อเชื่อมต่อ Database
   ตัวอย่าง:  server=10.10.10.97; database=RIS_BIDI2;User ID=sa;Password=mira001; Persist Security Info=false;Connection Timeout=30; Integrated Security=false; TrustServerCertificate=true;

   กรอก Connection String แล้วกด Enter

3. หากเชื่อมต่อสำเร็จ จะเข้าสู่เมนูหลัก


====================================
  เมนูหลัก
====================================

====================================
  Main menu
====================================
  [1] Convert Table (EXAMRESULT + NOTE + TEMPLATE)  <- default
  [2] RIS_EXAMRESULT
  [3] RIS_EXAMRESULTNOTE
  [4] RIS_EXAMRESULTTEMPLATE
  [5] Convert 0->N / 1->Y  (Define Table by you)
  [6] Setup delay
  [7] Exit

พิมพ์ตัวเลขแล้วกด Enter เพื่อเลือก
(กด Enter โดยไม่พิมพ์อะไร = เลือก 1 อัตโนมัติ)


====================================
  เมนู 1 — แปลงทุก Table พร้อมกัน
====================================

เลือก 1 เพื่อแปลงข้อมูลทั้งหมดใน 3 ตารางพร้อมกัน ได้แก่
  - RIS_EXAMRESULT
  - RIS_EXAMRESULTNOTE
  - RIS_EXAMRESULTTEMPLATE

โปรแกรมจะทำงานตามลำดับและแสดงผลดังนี้
  [OK]  ชื่อ record → Success   = แปลงสำเร็จ
  [WARN] ชื่อ record → ...      = ข้ามเพราะข้อมูลว่าง หรือไม่พบ
  [ERROR] ชื่อ record → ...     = เกิดข้อผิดพลาด

เมื่อเสร็จแต่ละตารางจะแสดงสรุป
  [OK]  Success : 100
  [ERR] Fail    : 2


====================================
  เมนู 2, 3, 4 — แปลงทีละ Table
====================================

เลือกได้ถ้าต้องการแปลงเฉพาะตารางใดตารางหนึ่ง

  [2] = RIS_EXAMRESULT
  [3] = RIS_EXAMRESULTNOTE
  [4] = RIS_EXAMRESULTTEMPLATE

การทำงานเหมือนเมนู 1 แต่รันเฉพาะตารางที่เลือก


====================================
  เมนู 5 — แปลงค่า 0->N / 1->Y
====================================

ใช้สำหรับแปลงค่าในตารางและ column ที่กำหนดเอง
โดยจะเปลี่ยนค่า 0 เป็น N และ 1 เป็น Y

ขั้นตอน

1. กรอกชื่อ Table
   เช่น  HrEmp

2. กรอกชื่อ Column ที่ต้องการแปลง
   เช่น  IS_ACTIVE

3. กรอกจำนวน Primary Key (1 หรือ 2)
   - ถ้า Primary Key มี 1 column → กรอก 1
   - ถ้า Primary Key มี 2 column → กรอก 2

4. กรอกชื่อ Primary Key Column
   เช่น  EMP_ID

5. ตรวจสอบข้อมูลที่กรอก แล้วยืนยัน Y เพื่อดำเนินการ หรือ N เพื่อยกเลิก

ตัวอย่างการแสดงผล
  1 : EMP001 -> Success (1 -> Y)
  2 : EMP002 -> Success (0 -> N)
  3 : EMP003 -> Fail (value = 'X')

  === Summary ===
  Success : 2
  Fail    : 1

หมายเหตุ
  - ถ้าค่าไม่ใช่ 0 หรือ 1 จะแสดงเป็น Fail และไม่เปลี่ยนค่า
  - ถ้าทุก record เป็น Y/N อยู่แล้ว จะแสดง "Column is Already Y And N"


====================================
  เมนู 6 — ตั้งค่า Delay
====================================

ใช้เมื่อต้องการให้โปรแกรมหยุดพักระหว่างการทำงาน
เพื่อลดภาระ Database

มี 2 แบบ

1. Delay per record
   หยุดกี่ ms หลังแปลงแต่ละ record
   เช่น กรอก 100 = หยุด 100ms ทุก record

2. Batch delay
   หยุดกี่ ms หลังครบทุก N record
   เช่น Batch delay = 1000, Batch size = 50
   = หยุด 1000ms ทุก 50 records

กรอก 0 = ไม่หยุด (default)


====================================
  เมนู 7 — ออกจากโปรแกรม
====================================

พิมพ์ 7 แล้วกด Enter เพื่อปิดโปรแกรม


====================================
  ข้อควรระวัง
====================================

- ควร Backup Database ก่อนรันโปรแกรมทุกครั้ง
- โปรแกรมจะแปลงเฉพาะ record ที่ยังไม่ได้แปลงเท่านั้น
  (ตรวจสอบจาก column JSON ที่เป็น NULL)
- หากโปรแกรมแสดง [ERROR] ควรตรวจสอบ Connection String
  และสิทธิ์การเข้าถึง Database
